# Loan Default Prediction

Predicts borrower loan defaults using Machine Learning models for smarter lending decisions.

---

## 📂 Project Structure

The repository contains the following directories and files:

### `Data/`
- Contains the dataset and development files used for model training and experimentation.
- Files include:
  - `Loan_Default.csv` – The main dataset used for training and testing.
  - `Loan_Prediction.ipynb` – Jupyter notebook containing the ML development workflow, model training, evaluation, and predictions.
  - `Dataset details` – Any other dataset-related files or documentation.

### `Report/`
- Contains the project report, written documentation, and figures.
- Files include:

  - `Flowchart.drawio` – Draw.io file showing system workflow.
  - `Flowchart.drawio.png` – PNG image of the system workflow.
  - `Methodology.drawio` – Draw.io file showing system methodology.
  - `Methodology.drawio.png` – PNG image of the system methodology.
  - `Pseudocode.md` – Markdown file containing system pseudocode.
